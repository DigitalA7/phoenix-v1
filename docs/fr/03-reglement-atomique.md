# Règlement atomique

Phoenix atomise la mise à jour du carnet et le transfert des actifs des deux parties. L’instruction de règlement vérifie les ordres, les comptes de marché, les vaults et les montants. Cette atomicité évite de laisser une moitié d’échange réglée si une contrainte échoue.

L’application doit toutefois contrôler les comptes et les limites avant signature.
