# Ordres et priorités

Les ordres sont positionnés selon leur prix et leur ancienneté. Les paramètres d’un ordre comprennent le côté, le prix, la quantité et les contraintes de validation. La priorité doit être respectée par toute intégration qui simule une exécution ou affiche une profondeur de marché.
