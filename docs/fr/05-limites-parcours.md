# Limites du parcours

Ce parcours couvre le carnet, la priorité des ordres, le règlement atomique et les comptes de Phoenix Legacy. Il ne constitue ni une validation de déploiement ni un audit de sécurité. Les garanties dépendent du programme déployé, de l’IDL, du cluster et des versions des clients.

Aucune installation, compilation ou exécution de test n’a été réalisée. Les scripts de build et de test du dépôt sont indiqués uniquement comme pistes de vérification ultérieure.
