# Modèle du carnet

Phoenix est un carnet d’ordres on-chain qui règle les échanges sans crank externe. Le programme conserve les ordres, les niveaux de prix et les quantités dans des comptes Solana. La lecture du carnet permet de comprendre la liquidité disponible avant de préparer une instruction.
