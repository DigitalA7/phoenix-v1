# Comptes et sécurité

Les comptes Solana portent le marché, les ordres, les lots de tokens et les autorités nécessaires. Le dépôt inclut un IDL, un fichier de licence MIT, une politique de sécurité et un audit OtterSec. Une intégration doit vérifier l’identifiant du programme, les propriétaires et les associations entre comptes.

Les vérifications de build mentionnées par le projet ne sont pas exécutées ici.
